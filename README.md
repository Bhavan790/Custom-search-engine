# 🚀 Custom Search Engine & Chrome Extension

A fast, interactive, dark-themed custom search engine designed to quickly search and filter through GitHub repositories with dynamic UI animations, star counters, language breakdowns, and a companion Chrome Extension.

![Live Demo](https://bhavan790.github.io/Custom-search-engine/)

---

## ✨ Features

- **Dynamic Dark Animated UI:** Features floating space/astronaut graphics, cursor spotlight effect, and glowing background elements.
- **Instant Filtering & Sorting:** Filter repositories by *Most Starred*, *Recently Updated*, or *Random Shuffle*.
- **Live Statistics:** Animated repo count-up and interactive top-language visual breakdowns.
- **Chrome Extension:** Search your repositories directly from your browser toolbar.
- **Hosted via GitHub Pages:** Fast and accessible everywhere.

## 🧩 Chrome Extension Installation

1. Clone or download this repository to your computer.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the `extension/` folder inside this repository.
5. Pin the extension to your toolbar for instant access!
